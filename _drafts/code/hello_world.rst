Hello World
===========

In programming Hello World is the first program that is written by a programmer. It is a simple program that prints Hello, 
World! on the screen. It is used to illustrate the basic syntax of a programming language for a working program. It is also 
used to verify that a language or system is operating correctly.

Here we provide examples of Hello World in different programming languages.

1. Vba
2. Python
3. C++

The code snippets are written in the respective languages and can be run in the respective environments.

THe mini first projects are a great way to get started with a new language and to get a feel for the syntax and 
structure of the language.

The objective to create a pop up to the user with the message "Hello, World!".
