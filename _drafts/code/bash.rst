Bash
==== 

Bash (Bourne Again Shell) is a Unix shell and command language that is widely used in Linux and macOS.

A list of useful commands:

.. code-block:: bash

    $ ls # list files and directories
    $ cd <DIRECTORY> # change directory
    $ pwd # print working directory
    $ mkdir <DIRECTORY> # make directory
    $ touch <FILE> # create file
    $ cp <SOURCE> <DESTINATION> # copy file
    $ mv <SOURCE> <DESTINATION> # move file
    $ rm <FILE> # remove file
    $ rm -r <DIRECTORY> # remove directory
    $ cat <FILE> # display file contents
    $ grep <PATTERN> <FILE> # search file for pattern
    $ chmod <PERMISSIONS> <FILE> # change file
