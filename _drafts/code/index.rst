Docs
====

Documentation of code is an important part of software development. It helps developers understand the code and
how to use it.  It also helps in debugging and maintaining the code.  Documentation can be in the form of comments in the code, README files, 
or separate documentation files.  Here we describe the latter.

These docs have been published using :doc:`Sphinx <sphinx>` which uses `Mark Up <https://en.wikipedia.org/wiki/Markup_language>`_ language :doc:`reStructuredText <rst>`. 
The HTML pages are hosted on :doc:`GitHub Pages <github_pages>` which is redirected to a custom domain  registered on 
:doc:`Google Domain <google>`.
