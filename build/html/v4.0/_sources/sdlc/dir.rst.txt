Directory Structure
===================


Best Practices:

Use dot-prefixed folders for configuration or metadata that you wish to keep out of regular view, particularly in Unix/Linux environments.

Be cautious when using this convention in cross-platform projects to avoid compatibility issues.


Best Practices:

Use underscores to improve clarity and readability in folder names.

Avoid overusing underscores, as excessive underscores can make folder names cumbersome and harder to read.
