Hello World
===========

Hello World is a simple program that prints "Hello, World!" to the screen. It is often used as a first program when 
learning a new programming language.  

.. note:: 
   The first known instance of "Hello, World!" being used in a computer program was in 1974 by Brian Kernighan in the book "The C 
   Programming Language". Since then, it has become a standard introductory program in programming tutorials and textbooks.

.. seealso::
   .. line-block::
      For more information on the history and usage of "Hello, World!" programs see
      https://en.wikipedia.org/wiki/%22Hello,_World!%22_program
