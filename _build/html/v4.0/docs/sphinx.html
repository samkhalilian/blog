Install#

Install a recent version of Python from https://www.python.org/downloads/.

Create and activate a Virtual Environment and install Sphinx.

$ pip install Sphinx

Quick Start#

Use Sphinx quick start to setup directories and basic configuration for a new project.

$ sphinx-quickstart --sep

Note

Option --sep will create separate source and build directories.

project
├── .venv
├── build
|── source
|   ├── conf.py
|   └── index.rst
└── requirements.txt

Where

  • build directory stores the generated HTML pages

  • source directory stores reStructuredText files used to edit the contents of HTML pages

  • conf.py is used to configure the HTML pages e.g. theme, extensions etc

source/conf.py#
project = "Learn to Code"
copyright = '2024, Sam Khalilian'
author = 'Sam Khalilian'
release = '0.0.1'
html_title = "Learn to Code"
html_theme = "pydata_sphinx_theme"
extensions = []

  • index.rst is the landing page

source/index.rst#
Learn to Code Documentation
===========================

...

Build#

To build and open the docs

$ sphinx-build -M html source build
$ start "" build\html\index.html

Themes#

A Sphinx theme helps shape your documentation’s appearance and usability. Sphinx provides a number of themes. In these docs, we use the PyData theme.

Install

$ pip install pydata-sphinx-theme

Set config.py

html_theme = "pydata_sphinx_theme"

ABlog#

We use ABlog a Sphinx extension that offers blog style features to tag pages as blog posts.

Install ABlog

$ pip install ablog

To tag a page as a blog post add the following to the top of a page

.. post:: <DATE>
   :category: <CATEGORY>
   :tag: <TAG>
   :author: <AUTHOR>

E.g.

source/release/release_1_0_0.rst#
.. post:: Mar 28, 2023
   :category: Release
   :tags: Release
   :author: Sam Khalilian

Multi-Version#

https://sphinx-contrib.github.io/multiversion/main/index.html#

Multi-versioning allows you to build documentation for multiple versions of your project. This is useful if you have a project that has multiple branches or tags, and you want to host documentation for each version.

Multi-versioning is done by creating a separate directory for each version of your documentation. Each version is built in its own Multi-version directory requires

$ pip install sphinx-multiversion

$ sphinx-build . .build/html

Pygments#

Pygments is a syntax highlighting engine written in Python. It is used to format code in many programming languages. It is used in Sphinx to highlight code blocks in documentation.

See also

https://pygments.org

Install#

To install Pygments, use pip.

$ pip install Pygments

Lexers#

Pygments can be used to highlight code in many languages. Those used in these docs:

Pygments Lexers in Sphinx used in these docs#

A list of all supported languages see https://pygments.org/languages/.

To specify the language of the code block, add the Lexer name after the double colons.

.. code-block:: python

    # Python code block
    def hello_world():
        print("Hello, World!")

Note

If a language is not supported by Pygments, the code block will not be highlighted.

If a language is not specified, the default language is Python.

LaTex
=====

LaTex is the defacto markup language used for mathematical documentation and can be integrated into Sphinx. 

.. seealso::

   https://www.latex-project.org

=======
Install
=======

Install Sphinx extension https://pypi.org/project/sphinx-mathjax-offline/

.. code-block:: bash
    
   >> pip install -U sphinx-mathjax-offline


Set conf.py

.. code-block:: python

   extensions = [
      ...
      'sphinx.ext.mathjax',
   ]

Data Templates#

$ pip install sphinxcontrib-datatemplates

# conf.py
extensions = [
    'sphinxcontrib.datatemplates',
]

datatemplates_github_issues = {
    'github_repo': 'samkhalilian/blog',
    'github

def fetch_github_issues(repo, token):
    import requests
    url = f'https://api.github.com/repos/{repo}/issues'
    headers = {'Authorization': f'token {token}'}
    response = requests.get(url, headers=headers)
    return response.json()
