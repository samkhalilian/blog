Docs
====

Documenting code is an important part of software development. It helps developers understand the code and how to use it. 
It also helps in debugging and maintaining the code. Documentation can be in the form of comments in the code, 
README files, or separate documentation files such as this one. These docs have been published using :doc:`Sphinx <sphinx>` to 
generate HTML pages hosted on :doc:`GitHub Pages <github_pages>` which are redirected to a custom domain  registered on a 
:doc:`Google Domain <google>`.
